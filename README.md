# 坦克大战 (Tank Battle)

一个用纯 HTML5 Canvas + JavaScript 实现的经典《坦克大战》(Battle City) 复刻版。单文件即可运行,无需任何依赖或构建步骤。

## 玩法

防守画面底部的基地(🛡️ 蓝色基地),消灭所有来犯的敌军坦克。敌军摧毁基地、或你的生命耗尽,则游戏结束。

## 特性

- 经典玩法:守卫基地、清剿敌军、逐关挑战
- 三种敌军:普通坦克、快速坦克、装甲坦克(需命中两炮)
- 丰富的场景元素:可破坏砖墙、钢铁墙、水面、草丛(可隐蔽坦克)
- 四种道具:火力升级 ★、无敌护盾 ⛨、全屏炸弹 💣、额外生命 +
- 粒子爆炸特效、射击/爆炸音效(Web Audio)
- 最高分本地存档(localStorage)
- 两套关卡地图,敌军数量与难度随关卡提升

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| Enter | 开始 / 重新开始 / 进入下一关 |
| P | 暂停 / 继续 |
| M | 静音 / 取消静音 |

## 运行

直接双击打开 `index.html` 即可游玩;或使用任意静态服务器:

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 在线试玩

部署到 GitHub Pages 后即可通过仓库页面在线游玩。
